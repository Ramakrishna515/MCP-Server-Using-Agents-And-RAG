# RAG Agent

Ask questions about your saved notes via retrieval + LLM.

- **Default tool:** `ask_rag`

## Tools

| Tool | Description |
| --- | --- |
| `ask_rag` | Ask a question about your saved notes using retrieval-augmented generation. |
| `index_notes` | Build or rebuild the vector index from saved notes using embeddings. |
| `list_notes` | List all saved notes. |
| `get_note` | Get a single note by its id. |
| `get_datetime` | Get the current date and time. |
