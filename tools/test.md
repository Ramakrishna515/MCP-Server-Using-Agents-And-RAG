# Test Agent

Research agent using TinyFish web search + notes tools.

- **Default tool:** `search_web`

## Tools

| Tool | Description |
| --- | --- |
| `search_web` | Search the web using TinyFish AI search API. |
| `add_note` | Create a new note with a title and content. |
| `list_notes` | List all saved notes. |
| `get_note` | Get a single note by its id. |
| `delete_note` | Delete a note by its id. |
| `get_datetime` | Get the current date and time. |
